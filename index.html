曲目没能加载

曲目放在单独的 JSON 文件里，浏览器不允许 file:// 直接读取，所以需要用一个本地服务打开。

仓库根目录执行 npm start（或 python -m http.server 8080），然后访问 http://localhost:8080。

想双击就打开的话，先跑一次 npm run build，生成的 dist/index.html 是自带曲目的单文件版本。
